React Gauge Chart is a reusable React component for displaying values as gauge charts. Built with D3.js, it supports animated needles, live updates, and custom value labels.

The chart's colors, number of segments, arc widths, and spacing can be adjusted through props. The demo shows several configurations, from a simple three-color gauge to more finely segmented charts.
